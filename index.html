Einstellungen

Ohne Key zeigt das Dashboard keine Kurs- und News-Daten — es gibt aktuell keine verlässliche kostenlose Kursquelle ohne Anmeldung (Stooq blockiert automatisierte Abfragen, Yahoo Finance erlaubt im Browser keine CORS-Anfragen). Mit kostenlosem Finnhub-Key (30 Sekunden Anmeldung, keine Kreditkarte) gibt es echten Live-Tick-Kurs per WebSocket plus News, Kennzahlen und Earnings-Termin. Key wird nur lokal in deinem Browser gespeichert, nie im Code oder Repo.

In Google Sheets: Datei → Freigeben → Im Web veröffentlichen → Format CSV → Link hierher kopieren. Erwartete Spalten: Plattform, Stück, Kaufkurs, Kaufdatum (Notiz optional). Eine Zeile pro Kauf, mehrere Zeilen pro Plattform werden automatisch summiert.
